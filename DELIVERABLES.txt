API REFERENCE
================================================================================

AutonomousTransferAgent Methods:
  - fetchBalance()                    → bigint
  - validateTransferCondition()       → boolean
  - executeTransfer(amount)           → string (txHash)
  - waitForTransaction(txHash)        → void
  - callComposableFunction(name, params) → object
  - checkBalanceThreshold(balance)    → void
  - executeTransferCycle()            → void
  - start()                           → Promise<void>
  - stop()                            → void
  - getReport()                       → AgentReport

AgentCoordinator Methods:
  - registerAgent(id, agent)          → void
  - registerFunction(name, handler)   → void
  - callFunction(name, params)        → Promise<object>
  - emitEvent(type, data)             → void
  - getEvents(type)                   → Event[]
  - getStatus()                       → object

ExecutionLogger Methods:
  - log(level, message, data)         → void
  - info(msg, data)                   → void
  - error(msg, data)                  → void
  - success(msg, data)                → void
  - getLogs()                         → ExecutionLogEntry[]

================================================================================
CONFIGURATION OPTIONS
================================================================================

Required:
  STARKNET_RPC_URL              - Starknet RPC endpoint
  STARKNET_ACCOUNT_ADDRESS      - Agent account address
  STARKNET_PRIVATE_KEY          - Account private key
  TOKEN_ADDRESS                 - ERC20 token contract
  TRANSFER_RECIPIENT            - Transfer destination

Optional (with defaults):
  MIN_BALANCE_THRESHOLD         - Default: 1e18 (wei)
  TRANSFER_AMOUNT               - Default: 1e17 (wei)
  ALERT_WEBHOOK_URL             - Slack webhook URL
  CHECK_INTERVAL_MS             - Default: 30000 (ms)

================================================================================
COMPOSABLE FUNCTIONS
================================================================================

Built-in Handlers:
  - notify-dashboard            - Send transfer notification
  - trigger-rebalance           - Initiate rebalancing
  - log-metrics                 - Record metrics

Multi-Agent Handlers:
  - broadcast-transfer          - Notify all agents
  - aggregate-metrics           - Collect metrics
  - coordinated-rebalance       - Multi-agent rebalance
  - emergency-stop              - Stop all agents
  - health-check                - Check all agents

Extensible:
  - Add custom handlers in callComposableFunction()
  - Register with AgentCoordinator
  - Discoverable via function registry

================================================================================
ALERT TRIGGERS
================================================================================

Critical Alerts:
  - Balance < MIN_BALANCE_THRESHOLD

Warning Alerts:
  - Balance drops >10% from previous check

Manual Alerts:
  - await sendAlert(message, severity)

Delivery:
  - Slack webhook (if ALERT_WEBHOOK_URL configured)
